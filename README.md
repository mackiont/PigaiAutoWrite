# 批改网作文自动录入工具 PigaiAutoWrite

一款基于 **Chrome 调试协议（CDP）** 的批改网（pigai.org）作文录入辅助工具。它会把你在界面里准备好的作文，以**输入法级别的输入方式**逐段写入批改网的写作页面——全程不经过剪贴板、不触发 `paste` 事件，因此不会被网页的"作文正文禁止粘贴"机制拦截。

**提供两个版本：**

- `pigai_autowrite.py` —— 命令行版（纯 Python 标准库，零第三方依赖）
- `pigai_autowrite_gui.py` —— 图形界面版（tkinter，作文粘贴框 + 实时日志）

## 功能特性

- 🚀 一键启动带调试端口的 Chrome（独立配置目录，不影响日常使用的浏览器）
- 🔐 登录态保持：登录一次后自动保存 cookie 到本地文件，下次运行自动恢复免登录
- 🔢 作文编号直达：只需填写作文编号（rid），页面地址自动生成
- ✍️ 正文逐段注入，**完整保留空格与换行**，自动识别正文首行的 `# 标题`
- 📊 录入完成后自动核对页面字数统计与首尾内容，不一致会告警
- 🛡️ 永不自动提交作文，最终提交由你确认内容后手动完成

## 环境要求

- Windows（默认；已内置 Chrome 常见安装路径，其他系统可修改脚本顶部的 `CHROME_CANDIDATES`）
- 本机安装 Chrome 浏览器
- Python 3.8+（命令行版零依赖；**GUI 版需要 tkinter**，Windows 官方安装包默认自带）

## 快速开始

### 克隆仓库

```
git clone https://github.com/mackiont/PigaiAutoWrite.git
cd PigaiAutoWrite
```

### 图形界面版（推荐）

```bash
python pigai_autowrite_gui.py
```

1. 在"作文编号"填写作文编号（地址栏会自动生成对应链接），或在地址栏直接粘贴作文页地址
2. 在正文框粘贴作文（空格、换行会完整保留）；标题可手动填，或让程序识别正文首行的 `# 标题`
3. 点击"开始录入"，在弹出的 Chrome 窗口中登录批改网
4. 程序自动完成录入并核对字数，你确认内容后自行点击页面上的"提交作文"

### 命令行版

```bash
python pigai_autowrite.py                # 运行后在控制台粘贴作文，以单独一行 EOF 结束
python pigai_autowrite.py essay.txt      # 直接读取作文文件
python pigai_autowrite.py -r 3444331     # 指定作文编号
python pigai_autowrite.py -r 3444331 essay.txt
```

### 命令行参数

| 参数 | 说明 |
|---|---|
| `essay`（位置参数，可选） | 作文文本文件路径；省略则控制台粘贴输入 |
| `-r, --rid` | 作文编号（纯数字），自动生成页面地址，优先于 `--url` |
| `-u, --url` | 完整作文页地址 |
| `-c, --cookie` | cookie 文件路径（恢复与保存都使用它），默认 `pigai_cookies.json` |
| `--no-cookie` | 本次运行不读取/保存 cookie |
| `-h, --help` | 查看帮助 |

## cookie 免登录说明

- 首次运行需要手动登录一次；进入写作页后程序会把批改网相关 cookie 保存到 `pigai_cookies.json`（GUI 可通过"浏览..."指定其他位置）
- 之后每次运行会先恢复 cookie 再打开作文页：登录态有效则直接进入写作页；失效则退回手动登录，登录后自动刷新 cookie 文件
- ⚠️ **cookie 文件包含登录凭据，请妥善保管，切勿外传**

## 工作原理（简述）

程序通过 `--remote-debugging-port` 启动 Chrome，使用 CDP 的 `Input.insertText` 接口分块注入文本。该接口与输入法打字等同，不经过剪贴板、不产生粘贴事件；注入后还会触发 `input`/`keyup` 事件，保证页面的字数统计与自动保存逻辑正常感知输入。
